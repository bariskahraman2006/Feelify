# Feelify: AI-Powered Music Discovery Platform 🎧

An AI-powered music discovery platform that analyzes your current mood, favorite artists, and genres to curate the perfect Spotify playlist in seconds.

## ✨ Features
* **Context-Aware AI Processing:** Uses Google Gemini to understand complex emotions and daily situations.
* **Facial Emotion Recognition:** Real-time mood detection via webcam using `face-api.js`.
* **Seamless Spotify Integration:** Fetches user top tracks, dynamically maps genres, and automatically creates playlists directly on the user's Spotify account.
* **Algorithmic Profiling:** Visualizes the user's current music taste with Chart.js based on recent listening history.
* **Automated Ticketing:** Internal support system via Node.js and Nodemailer.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Chart.js, face-api.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose)
* **APIs:** Spotify Web API, Google Gemini API
